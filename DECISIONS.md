# Решения и допущения

- Все постановщики видят все задачи и управляют ими независимо от авторства.
- Исполнитель меняет только допустимые статусы назначенных ему задач; поля задачи редактирует постановщик.
- Каталог сотрудников для вошедших пользователей содержит только id, имя и роль, без email.
- История включает создание задачи и смены статуса. Перенос/переназначение не создают ложных событий смены статуса.
- Задача удаляется вместе с историей. Самостоятельное изменение/удаление записей истории через таблицу запрещено.
- После переназначения прежний исполнитель теряет доступ в новых серверных запросах. Новый видит прежнюю историю. Уже загруженные сведения нельзя отозвать ретроактивно; интерфейс перечитывает данные при возврате фокуса, ручном обновлении и изменении.
- Объект удаляется только пустым: сначала удалить или перенести его задачи. Массового каскадного удаления задач объекта нет.
- Статус, автор, дата и история сохраняются при переносе и переназначении.
- Сессия хранится в памяти; после перезагрузки требуется вход. Нет realtime, автоматического повтора изменений и пагинации; одной страницы достаточно для демонстрационных данных.
- Публичные Auth/API, запрет регистрации, TLS/headers и точный статический артефакт должны быть проверены после облачного развёртывания. Облачная публикация пока не завершена.
